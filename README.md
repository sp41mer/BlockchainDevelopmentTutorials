# BlockChain Development

Здесь находятся материалы для моих курсов / туториалов по разработке на BlockChain.

В каждой теме два вида файлов: полное решение с построчными комментариями и папка `Architecture` — тот же файл, но только с комментариями, без кода. Сначала попробуй написать код по каркасу из `Architecture`, потом сверься с решением.

## Где что лежит:

Папка Ethereum - материалы и исходные коды для моих курсов по разработке в блокчейне Ethereum.
Здесь ты найдешь информацию о том, как организовать свое рабочее окружение, и краткий путеводитель от написания простейшено смарт-контракта в блокчейне Ethereum до написания полноценного DApp взаимодействущего с твоим контрактом через Web3.JS

⚠️ Примеры в папке Ethereum написаны для Solidity `^0.4.x` и исполняются компилятором той версии. Как учебное пособие по концепциям они рабочие, но паттерны местами устарели — не разворачивай эти контракты в основной сети, для боевого кода смотри [OpenZeppelin](https://docs.openzeppelin.com/contracts/).

Папка Solana - та же простая логика (счетчик), но на Rust в модели Solana: состояние живет в аккаунтах, программа получает их в каждый вызов. Хороший способ почувствовать разницу моделей после Ethereum.

Папка Cosmos - контракт-счетчик для CosmWasm (Rust): instantiate / execute / query, свое хранилище у контракта, проверка владельца как onlyOwner в Solidity.

Папка HyperledgerFabric - чейнкод на Go для приватного блокчейна: создание, чтение и передача актива в world state. Ни газа, ни токенов - совсем другой мир, но структура кода намеренно та же.


## FAQ

Точно так же, как и в любом подобном репозитории: форк -> пулреквест. Было бы клево, если ты поставишь в имени пулреквеста [Extension], так я смогу очень быстро сделать ревью и смерджить.

Самый простой способ - создать Issue. Мне придет оповещение и я смогу ответить максимально оперативно.
Кроме того, можно написать на почту `blockchaintuts@gmail.com`.
Я стараюсь оперативно отвечать в почте, но все-таки более предпочтительно писать в Issues, так как твой вопрос может быть полезен не только тебе.
